## Deploy

1. Download and extract the ZIP archive.
2. Open https://github.com/BabakHeidari/babakheidari.github.io on the `main` branch.
3. Upload/replace **`index.html`**, **`styles.css`**, and **`assets/babak-heydari.jpg`**, keeping the `assets/` directory path intact.
4. Commit the change. GitHub Pages will serve the update at https://babakheidari.github.io/ once deployment completes.

If editing in GitHub's web UI, use **Add file → Upload files** at the repository root and drag the three-file folder structure from the extracted package, keeping `assets/babak-heydari.jpg` inside `assets/`. Alternatively, commit using Git to preserve paths.

This website is static HTML + CSS, with no build step or dependencies. The public page intentionally excludes your phone number. Existing `cost_determination_system/` files are unaffected.
